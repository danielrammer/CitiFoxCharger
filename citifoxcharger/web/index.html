Vehicle charging limit

With a readable vehicle limit, manual Start sets and verifies the target. Otherwise M+ charging is monitored using SMARTFOX energy and vehicle reports. The estimated SOC is marked *. Missing cloud data do not stop charging. Measurement gaps increase uncertainty, with a target +5 fallback. Old starting SOC, capacity and losses affect accuracy. Charging profiles are not edited.

Isolated vehicle-limit test

Sending a test limit alone never starts charging or changes SMARTFOX mode. A separate supervised trial can explicitly start with an unconfirmed limit. Existing charging schedules are not edited.

  1. End any current charging session.
  2. In CitiFoxCharger select Charger → Off. Wait for Off and 0 kW.
  3. Choose a test limit and send it once. Do not use Force charge for this test.
  4. Check the actual vehicle limit in MyŠkoda or the car if displayed. API acceptance alone is not confirmation.
  5. Send the normal 80% limit, then end the test. The charger stays Off. Select A+ separately when you want normal operation again.

Exact integer, no rounding. The vehicle may reject values such as 37%.

Vehicle-stop trial: no app stop at target; maximum 60 minutes after Start. Manual stops and app fallbacks make the test inconclusive.

End isolated limit test

Ending the test sends no command and leaves the charger Off. An accepted 80% request does not prove restoration. Check the actual vehicle limit before allowing normal charging. If the limit is not visible in MyŠkoda or the car, it remains unconfirmed.
